# Rithvik Pennepalli — Creator & Video Editor

An editorial portfolio centered on Rithvik Pennepalli: creator, freelance short-form video editor, and Uber brand ambassador.

The homepage features Rithvik’s verified public Instagram, TikTok, and YouTube audience snapshots and selected original content. A separate editing case study highlights three months of work for Armaan Talreja, while the contact page supports brand, UGC, and editing inquiries.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
